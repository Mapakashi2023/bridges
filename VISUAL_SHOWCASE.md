## 🎭 Animation Principles

### Easing Functions:
```
Entrance:  ease-out    (Quick start, slow end)
Exit:      ease-in     (Slow start, quick end)
Hover:     ease-in-out (Smooth both ways)
Spring:    Spring physics (Natural bounce)
```

### Duration Guidelines:
```
Micro:     100-200ms   (Hover effects)
Standard:  300-500ms   (Page transitions)
Complex:   500-800ms   (Multi-step animations)
Ambient:   2-20s       (Background effects)
```

### Stagger Delays:
```
Cards:     100ms       (Between each card)
Rows:      100ms       (Between each row)
Elements:  50-100ms    (Between related items)
```
